# Travel and Tourism Management System

## Overview

This project is a Travel and Tourism Management System developed using React JS and Bootstrap. It helps users explore travel packages, submit enquiries, and manage their accounts through login and signup features.

## Features

* Home Page
* About Us Page
* Packages Page
* Enquiry Panel
* User Login and Signup
* Forgot Password
* Terms and Conditions
* Local Storage Authentication
* Responsive Design

## Technologies Used

* React JS
* React Router DOM
* Bootstrap 5
* HTML
* CSS
* JavaScript

## Run the Project

```bash
npm install
npm start
```

The application will run on:

```plaintext
http://localhost:3000
```
